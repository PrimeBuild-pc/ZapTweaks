# ZapTweaks v1.13.0

## Apps, services and presets

- Installed apps now include Win32/MSI programs from the registry, with sizes, safety labels and an uninstall queue: preview, open processes from the program folder, simulation, a mandatory restore point, skip/stop. Uninstall strings are parsed without ever running shells or script hosts.
- Leftover scan after uninstall (folders, shortcuts, registry keys, Run values, tasks, firewall rules) with confidence levels. Only "Sure" items start selected; registry keys, tasks and rules are backed up, files go to the Recycle Bin, and shared Windows locations are refused.
- New Processes and Services tabs. Services carry a curated safety class (can disable / depends on use / keep) with what stops working, a start-type menu and an undo. Services of installed antivirus, antispyware and firewall products (Windows Security Center) are always kept.
- Presets in Guided setup: five stepped presets with a per-PC preview (to do / already set / skipped with the reason), "Undo preset", and user presets saved to the real Documents folder.
- Battery health card, CPU clock and core parking, firmware thermal zones and an app history (SRUM) view in Diagnostics.

## Faster and cleaner

- Startup state checks no longer start a PowerShell per tweak: services and registry values are read natively. Tweak states are ready in about 5 s instead of 20 s.
- The app store shows its list immediately; installed state follows when winget answers. A published catalog older than the one in the app is ignored, which also fixes stale "by PrimeBuild" attributions on third-party apps.
- Hardware detection reads mice and keyboards in batches (about 3 s faster).
- PowerShell started from a PowerShell 7 terminal no longer loads PowerShell 7 modules, which broke signature, ACL and hash checks.

## Fixes

- The CPU idle demote/promote tweak used a non-existent powercfg alias and silently did nothing. It now applies, reads and reverts to the exact Windows defaults (verified in a clean Windows 11 VM). Checks of hidden processor settings now read their real values.

## Interface

- Settings are grouped in sections (General, Modes, Updates, Maintenance, About) with Windows 11 style cards.
- Expert mode can be switched on from Home.
- Every section has a page title; tabs fit their labels and all have icons; row actions use standard buttons, with the accent color kept for the main action.
- All seven languages are complete.

## Verification

639 automated tests, `flutter analyze` clean, Release build. Uninstall, leftovers, presets and the idle tweak were exercised in a clean Windows 11 VM restored to a checkpoint afterwards. This release does not claim Authenticode signing.
