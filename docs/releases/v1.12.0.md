# ZapTweaks v1.12.0

## Reliability and catalog updates

- Fixed multi-app plans: distinct targets can share an operation definition, with separate snapshots, journal entries and rollback. Duplicate writes to the same target remain blocked, and dependent operations wait for every prerequisite target.
- Added official-source, exact-asset, SHA-256 and size checks to the updater and PowerShell installer. Desktop downloads are streamed with progress and bounded trusted-host redirects; dry-run never downloads or starts an installer. The launch helper rechecks the installer hash, and failed downloads are cleaned up.
- Added a validated remote app catalog shared by the app store, search and setup, with offline cache and bundled fallback. Future app additions no longer require another ZapTweaks binary release. Catalog data cannot introduce commands/scripts.
- Added NV-UV-Play and retained the existing DLSS-NR-on-AMD launcher without duplication. Both show upstream requirements and warnings. External utilities and unavailable winget inventories no longer misleadingly appear as uninstalled.
- Fixed GPU telemetry: process samples are grouped by physical engine and adapter, not summed across unrelated engines/GPUs. VRAM capacity uses the matching DXGI adapter's 64-bit dedicated memory size, and the dashboard can select a GPU. Missing readings are explicitly unavailable, including localized N/D in Italian.

## Verification

Regression tests cover multi-target journal/rollback and dependencies, updater tampering/redirects/progress/dry-run, mocked PowerShell bootstrap execution, remote/offline/invalid catalog handling, app-store inventory states, GPU aggregation and GPU selection. A read-only physical check on an AMD Radeon RX 6950 XT verified both native and PowerShell sampling, including matching 16 GB VRAM capacity. No clock, voltage, driver or Windows configuration changes were performed during that physical check.

Update hashes are authenticated through the official GitHub HTTPS API; this release does not claim Authenticode signing. NV-UV-Play is alpha software; DLSS-NR-on-AMD is experimental and requires compatible hardware and a legitimately obtained DLSS DLL. Read the upstream instructions before use.
